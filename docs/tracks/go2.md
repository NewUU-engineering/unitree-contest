# Трек 1 — Unitree Go2

## «Автономный скаут полей и садов»

**Фокус:** навигация, компьютерное зрение, построение карт, автономное
патрулирование.

Четвероногий робот заменяет агронома на регулярном обходе: проходит по
межрядьям, осматривает растения, фиксирует проблемные места и отдаёт готовый
отчёт с координатами. Ходовая часть робота при этом не является предметом
соревнования — вам не нужно учить его ходить, для этого в
[Starter Kit](../starter-kit.md) есть готовый контроллер локомоции, принимающий
команду скорости.

---

## Этап 1 — Симуляция

**Среда:** виртуальный сад и теплица с рядами растений.

**Задача:** пройти по межрядьям, обнаружить поражённые болезнью растения и
спелые плоды средствами YOLO и OpenCV, вывести координаты находок.

**Результат:** скрипт навигации и модуль детекции, выдающий структурированный
список объектов с их положением на карте.

Что важно на этом этапе:

- пройти маршрут целиком, не задев растения и не застряв в конце ряда;
- отличить больное растение от здорового и спелый плод от незрелого;
- корректно перевести детекцию с изображения в координаты на карте;
- не выдавать ложных срабатываний — они штрафуются наравне с пропусками.

---

## Этап 2 — Реальный Go2

**Локация:** полигон с искусственными грядками и размеченными маркерами
агро-болезней.

**Задача:** автономно пройти маршрут, считать состояние растений, сгенерировать
отчёт для фермера.

Здесь к алгоритму добавляется физика: неровный грунт, проскальзывание лап,
переменное освещение и блики на листьях, шум лидара и камеры. Детектор,
обученный только на рендере из симулятора, почти наверняка потеряет точность —
готовьтесь дообучать модель на реальных снимках и проверять работу при разном
освещении.

!!! tip "Совет"

    Сделайте отчёт машиночитаемым и человекочитаемым одновременно: JSON для
    судейского скрипта и краткая сводка для агронома. Качество отчёта входит в
    оценку.

---

## Этап 3 — Финал

**Задача:** ограниченное по времени патрулирование с динамическими
препятствиями и передачей координат найденных объектов на центральный сервер.

Обстановка меняется прямо во время прогона: на маршруте появляются препятствия,
которых не было при построении карты. Робот должен их объехать, не потеряв
локализацию и не выпав из графика. Найденные объекты передаются на сервер по
мере обнаружения, а не одним пакетом в конце.

## Что даёт Starter Kit

```python title="go2_scout.py"
from agrokit.go2 import Go2

go2 = Go2(sim=True)

for row in go2.field.rows:
    go2.nav.follow_row(row, speed=0.4)          # (1)!

    for det in go2.vision.detect(model="agro_yolo"):
        if det.label in ("powdery_mildew", "leaf_rust"):
            go2.report.add_finding(det.label, go2.nav.pose, det.score)

go2.report.export("field_report.json")
```

1.  Под капотом Nav2 строит траекторию, а контроллер локомоции превращает
    команду скорости в движение лап. Тот же вызов работает на реальном роботе.

Доступные модули:

| Модуль | Назначение |
|---|---|
| `go2.nav` | Движение к точке, следование по ряду, объезд препятствий, текущая поза |
| `go2.vision` | Кадры с камеры, запуск детектора, перевод детекции в координаты карты |
| `go2.map` | Построение и чтение карты, разметка рядов поля |
| `go2.report` | Накопление находок и выгрузка отчёта в JSON |

Полное описание — в разделе [Starter Kit](../starter-kit.md).
