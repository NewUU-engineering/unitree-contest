# AgroTech Robotics Challenge

**Республиканское соревнование по робототехнике и искусственному интеллекту на
платформах Unitree Go2 и Unitree G1.**
{ .lead }

Участники создают алгоритмы для мониторинга садов, сбора и сортировки урожая:
сначала в симуляторе на собственном ноутбуке, затем на настоящих роботах.
Соревнование проводит инженерная школа New Uzbekistan University.

## Почему сельское хозяйство

Агросектор — та область, где автономные роботы дают эффект немедленно: обход
садов и теплиц, ранняя диагностика болезней растений, сбор и сортировка урожая.
Задачи соревнования построены вокруг реальных сценариев, а не абстрактных
полигонов, поэтому решения команд имеют прикладную ценность за пределами
контеста.

## Порог входа снижен намеренно

!!! tip "Ни робота, ни видеокарты для старта не требуется"

    Первый этап проходит целиком в симуляторе. Достаточно ноутбука с Docker —
    подойдёт Linux, Windows и macOS, включая машины на Apple Silicon.
    Дискретная видеокарта не нужна: симулятор работает на процессоре и
    открывается прямо в браузере.

Организаторы дают готовый фреймворк, контейнер с окружением и базовые примеры
для обоих треков, которые уже работают из коробки. Задача участника —
улучшать алгоритм, а не две недели бороться с установкой зависимостей.

## Sim-to-real без переписывания кода

Ключевое инженерное решение соревнования: симулятор и реальный робот
обмениваются **одними и теми же сообщениями** по общей шине DDS. Разница между
запуском на ноутбуке и на полигоне сводится к двум параметрам подключения.

=== "Симуляция"

    ```python
    robot = Go2(sim=True)   # domain_id = 1, интерфейс "lo"
    ```

=== "Реальный робот"

    ```python
    robot = Go2(sim=False, iface="enp3s0")   # domain_id = 0
    ```

Отлаженный в симуляции код переносится на железо без правок логики. Подробности
и полный список зафиксированных версий — в разделе [Стек](stack.md).
