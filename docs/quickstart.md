# Быстрый старт

Ниже — путь от чистой машины до первого запущенного робота в симуляторе.
Займёт около пятнадцати минут, из которых большая часть уходит на скачивание
образа.

!!! note "Статус"

    Образ и репозиторий Starter Kit публикуются вместе с открытием регистрации.
    Команды ниже отражают итоговый порядок работы.

---

## Что понадобится

- Компьютер с **Docker** — Linux, Windows или macOS, включая Apple Silicon.
- Около **10 ГБ** свободного места на диске.
- Браузер.

Видеокарта не нужна: симулятор первого этапа работает на процессоре.

??? tip "Установка Docker"

    - **Windows и macOS** — [Docker Desktop](https://www.docker.com/products/docker-desktop/).
      На Windows при первом запуске согласитесь на установку WSL 2.
    - **Linux** — пакет `docker.io` из репозитория дистрибутива либо
      [официальная инструкция](https://docs.docker.com/engine/install/).

---

## Шаг 1. Запустить окружение

```bash
docker run --rm -it -p 6080:6080 \
    -v "$PWD/solution:/workspace/solution" \
    ghcr.io/newuu-engineering/agrokit:latest
```

Что происходит: контейнер поднимает симулятор, ROS 2 и веб-интерфейс, а папку
`solution` из текущей директории пробрасывает внутрь. Ваш код остаётся на
вашей машине — контейнер можно перезапускать сколько угодно, ничего не
потеряется.

!!! tip "Windows"

    В PowerShell замените `$PWD` на `${PWD}`, а перенос строки `\` — на
    обратную кавычку `` ` ``. Проще всего запускать команду из WSL.

---

## Шаг 2. Открыть симулятор

Перейдите в браузере по адресу **[http://localhost:6080](http://localhost:6080)**.

Откроется рабочий стол с окном симулятора — робот стоит на стартовой позиции
сцены. Никаких X11, VNC-клиентов и драйверов устанавливать не нужно.

---

## Шаг 3. Запустить пример

В новом терминале подключитесь к работающему контейнеру:

```bash
docker exec -it $(docker ps -q -f ancestor=ghcr.io/newuu-engineering/agrokit:latest) bash
```

И запустите базовое решение своего трека:

=== "Трек 1 — Go2"

    ```bash
    python examples/go2_scout.py
    ```

    Робот пройдёт по первому межрядью, найдёт растения с признаками болезни и
    сохранит отчёт в `field_report.json`.

=== "Трек 2 — G1"

    ```bash
    python examples/g1_sorting.py
    ```

    Гуманоид возьмёт объекты со стола щипковым хватом и разложит их по лоткам
    в соответствии с распознанной категорией.

---

## Шаг 4. Написать своё решение

Скопируйте пример в рабочую папку и начните его менять:

```bash
cp examples/go2_scout.py solution/main.py
```

Файл лежит на вашей машине в папке `solution`, поэтому редактировать его можно
привычным редактором — изменения сразу видны внутри контейнера. Перезапуск
контейнера не требуется, достаточно заново запустить скрипт.

---

## Шаг 5. Проверить себя судейским скриптом

```bash
agrokit-judge run solution/main.py --scene orchard_qualifier
```

Скрипт прогонит решение на той же сцене и по тем же правилам, что применяются
при оценке, и выведет разбивку баллов по критериям. Прогон детерминирован:
повторный запуск даёт тот же результат.
